# Академия героев — Репетитор для второго класса

Сайт: https://dolzenkoanna90-hash.github.io/repetitor-miroslav/

58 тем, 174 ступени, 522 вопроса по математике, русскому языку, чтению, окружающему миру и английскому. Все главы, темы и сложности доступны сразу. Отметки освоения и награды выдаются за результат, а не за открытие темы. Проходить ступени можно в любом порядке. Письмо, пересказ и устные задания проверяются вместе с взрослым.

ИЗО, музыка, труд и физкультура не включены. Все файлы приложения и изображения находятся в репозитории; для занятий нет запросов к OpenAI, Telegram, внешним шрифтам или API. Ссылки на учебные источники необязательны для работы. GitHub Pages работает независимо от компьютера владельца. Доступность github.io зависит от сети пользователя.

Прогресс хранится в localStorage браузера. При переходе с прежнего адреса перенесите JSON через раздел «Для родителей»: скачать прогресс на прежнем сайте, затем импортировать здесь. Обновление по тому же адресу сохраняет данные. Между устройствами автоматической синхронизации нет.

## Локальный запуск и проверки

Node.js 18+: `node server.js`, затем http://127.0.0.1:4173/.

Проверки:

```
node scripts/build-offline.cjs
node tests/progress.test.cjs
node tests/progression.test.cjs
node tests/year-course.test.cjs
```

Автономный HTML генерируется сборкой; файл не дублируется в репозитории. PWA сохраняет ресурсы для повторного открытия без сети после первой успешной загрузки. Браузер может очистить кэш при нехватке места.

## Публикация

GitHub Pages: ветка main, каталог /. `.nojekyll` отключает обработку Jekyll. Все пути относительные и работают в /repetitor-miroslav/. После обновления ресурсы загружаются с сайта; версия service worker обновляется в sw.js.

Изображения персонажей предоставлены пользователем; отдельная лицензия на их распространение не предоставляется. Учебная карта и источники — docs/CURRICULUM.md. Приложение — семейный тренажёр и дополнение к школьным урокам.
